## 🔧 Updating Placeholders
When your personal links are ready, simply open `src/data/portfolioData.ts` and replace:
- `socialPlaceholders.github` with your GitHub profile URL.
- `socialPlaceholders.linkedin` with your LinkedIn profile URL.
- Project `liveDemoUrl` and `githubUrl` with your deployed project demos and GitHub repositories.
